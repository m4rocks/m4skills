---
name: report
description: Final message when finishing a task.
---

Aim for under ten lines. Open with one sentence on the outcome, then add only the sections that have items: Needs you (actions the user must take), Unverified, Risks. One short bullet per item, no sub-bullets, no file-by-file tour of the diff and no story of how you got there. Name passing checks in a single line and quote output only for failures. Never tuck an action or caveat into a sentence about something else.
