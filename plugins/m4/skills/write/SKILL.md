---
name: write
description: Use before writing prose that lands somewhere, such as docs, a README, pull request text or a message to another person, and whenever the user says unslop, de-AI or humanize. Skip for code, code comments, commit messages and chat replies.
---

Write it once, avoiding the patterns below; when the user hands you text, edit that. Keep the meaning and tone, and add nothing the source didn't say. Where a rule wants a mechanism or number you don't have, cut the sentence.

- **Superficial -ing phrases** ("highlighting...", "ensuring..."). Delete them or back them with a source.
- **Vague attributions** ("experts believe"). Name the source or delete.
- **AI vocabulary**: additionally, crucial, delve, enduring, enhance, fostering, garner, interplay, intricate, landscape, pivotal, showcase, tapestry, testament, underscore, vibrant. Use plain words.
- **Fancy "is"**: serves as, stands as, boasts, features. Say "is" or "has".
- **"Not just X, but Y."** State the point.
- **Forced groups of three.** Use the natural number.
- **Synonym cycling.** Pick one term and repeat it.
- **False ranges**: "from X to Y" with no real scale. List the items.
- **Em dashes.** Use none, and no en dashes, parentheses or hyphens in their place; use a period or comma.
- **Mid-sentence colons.** Use colons before a list or example, not as connectors.
- **Bold overuse.** Don't bold every name.
- **Inline-header lists** where a bold label restates the line ("**Performance:** Performance improved"). Write prose. A bold lead-in that names the item before new detail is fine.
- **Title case headings.** Use sentence case.
- **Decorative emojis.** Remove them.
- **Curly quotes.** Use straight ones.
- **Chatbot phrases**: "I hope this helps!", "Certainly!". Remove them.
- **Sycophancy**: "Great question!" Answer directly.
- **Filler**: "in order to" is "to", "due to the fact that" is "because".
- **Stacked hedges.** One "may" is enough.
- **Generic conclusions** ("the future looks bright"). State plans or facts.
- **Abstract metaphor nouns**: substrate, wedge, vector, locus, nexus, primitive, harness, surface, bedrock, scaffolding, paradigm, gold-plating, ratchet, north star, flywheel. Use the concrete word.
- **Feelings instead of facts.** "SQL you can read" becomes "`.toSQL()` returns the exact string sent to the database". Cut a sentence that could sit unchanged in another project's docs.
- **Dense sentences.** One idea per sentence.
- **Passive voice.** Name the actor unless it's unknown.
- **Adverbs.** Use a stronger verb or the number.
- **Fancy words**: utilize and leverage are "use", facilitate is "help", numerous is "many".
- **Mannered prose**: aphorisms, rhetorical fragments, personified code, figurative verbs. Say it literally.
- **Over-compression**: dropped articles, verbless fragments, arrows, abbreviations. Write whole sentences.
