---
name: babysit
description: Use when the user says babysit, watch or monitor a pull request.
---

After each push, wait with `gh pr checks <n> --watch`, then read only comments newer than the push. Verify each bot finding against the code: fix real ones, reply with a reason to the rest. List extras as follow-ups. Rebase when behind. Stay silent while nothing changes. Never merge unless told.
