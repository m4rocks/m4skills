---
name: implement
description: Use when the user asks to add, build, implement or create something new.
---

Follow m4:autonomy, m4:repo and m4:code. Find the closest existing feature with a search, and read only what the change touches. Name the data shape first, then build the smallest thing that meets the goal. Keep rules in one structure, validate at boundaries and make illegal states unrepresentable. Add tests per m4:test, only where it calls for them. Prove it per m4:verify.
