Get a review from GPT Sol through whatever agent tool can run it, else from one cold read-only subagent. Brief it with repo, base, goal, out-of-scope and check results, and ask for bugs with file:line labeled blocker, should or nit. Verify each, fix with the smallest change, rebut with evidence, list extras as follow-ups. At most 3 rounds; later ones cover only changes and open items.
