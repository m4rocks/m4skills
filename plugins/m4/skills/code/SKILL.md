name: code
description: Use when writing or restructuring code, for how it should read, be reused and stay maintainable.
---

Write for a maintainer two years out: clear names, an obvious flow. Comments say why; code that needs a what-comment gets restructured instead. Reuse before writing. For a feature like an existing one, copy it; if the copies would need syncing by hand, extract the shared part so they can't drift.
