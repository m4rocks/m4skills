---
name: autonomy
description: Use when deciding whether to stop and ask the user, or when the user asks when to block, or says just do it or don't ask.
---

Never block on reversible work: decide, do it, list the calls. Ask only before irreversible or outward-facing steps: push, merge, delete data, add a dependency, touch issues, production or people. Say no when a request would hurt the project. Warn when the user seems to miss something important, until they dismiss it. Report per m4:report.
